SARBIT: ALL THE DATA USED, WITH LINKS
=====================================

Every data source in the game, the slides and the pipeline, as of 15 November 2026. Part A is NASA (including partner data
that NASA hosts). Part B is everything else. Part C lists what the team made from the NASA data, so it is never mistaken
for a NASA product.

The NISAR file links come from NASA's ASF DAAC archive, looked up by each mission's place and dates. Per file:
download .h5 needs a free NASA Earthdata login · ASF search opens the file in ASF's search page (press "Search") ·
metadata opens the file's record directly, no login.

THE CHALLENGE'S OWN DATA LINKS (DANCING WITH THE SARS → RESOURCES)
==================================================================

From https://www.spaceappschallenge.org/2026/challenges/dancing-with-the-sars/?tab=resources

NASA data & resources we used:

- ASF Data Search Vertex: https://search.asf.alaska.edu/ — every NISAR radar file in the game came from this NASA archive (all 17 are listed in A1 below).
- NISAR Data User Guide: https://nisar-docs.asf.alaska.edu/ — the reference for the GCOV product the pipeline reads (grids, projection, polarisations).
- NASA Earthdata Search: https://search.earthdata.nasa.gov/search — the NASA Earthdata system the NISAR and GIBS data belong to.
- Intro to Synthetic Aperture Radar (SAR): https://www.earthdata.nasa.gov/learn/earth-observation-data-basics/sar — the team's SAR background (shared in the team chat on 28 Sep 2026); the game's explanations (bright/dark echoes, polarisation) follow it.

NASA links from the same list that we did not use: NASA ARSET Trainings (https://appliedsciences.nasa.gov/get-involved/training),
Intro to Remote Sensing (https://www.earthdata.nasa.gov/learn/earth-observation-data-basics/remote-sensing), NISAR StoryMaps
(https://nisar.jpl.nasa.gov/applications/arcgis-storymaps/), NISAR Applications White Papers
(https://nisar.jpl.nasa.gov/applications/societal-benefit/), UAVSAR Postcards (https://uavsar.jpl.nasa.gov/education/postcards.html).

Space Agency Partner resources on the challenge page, not used: CSA RCM data (https://donnees-data.asc-csa.gc.ca/en/dataset/rcm),
CSA SAR Python tutorial (https://github.com/asc-csa/Synthetic_Aperture_Radar_Tutorial), CSA RADARSAT-1 data
(https://donnees-data.asc-csa.gc.ca/en/dataset/radarsat1), CONAE SAOCOM catalogue (https://catalogos.conae.gov.ar/catalogo/catalogoSatSaocomInfo.html).
Partner data we do use arrives through NASA: ISRO (NISAR co-builder) and ESA Sentinel-2 (inside NASA's HLS). Partner list:
https://www.spaceappschallenge.org/2026/space-agency-partners/

A · NASA DATA AND RESOURCES
===========================

A1 · NISAR radar (NASA-ISRO), Level-2 GCOV, from the ASF DAAC
-------------------------------------------------------------

- Product: NISAR L-band Geocoded Polarimetric Covariance (GCOV), archived at the Alaska Satellite Facility DAAC (NASA
  Earthdata), in the collections NISAR_L2_GCOV_BETA_V1, NISAR_L2_GCOV_PROVISIONAL_V1 and NISAR_L2_GCOV_V1 (each
  download link shows which).
- Search: https://search.asf.alaska.edu/ (dataset NISAR) · archive API used for this list:
  https://api.daac.asf.alaska.edu/services/search/param?dataset=NISAR&processingLevel=GCOV
- What the game takes from each file: the HH and HV backscatter grids (HH only where noted), cut to the mission box.
- Mode codes in the names: DHDH = dual-pol HH+HV · SHSH = HH only · QPDH = quad-pol.
